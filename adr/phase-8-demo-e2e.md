# Phase 8 — الواجهة والاختبار الشامل

## التنفيذ

أنشئ `app/demo_ui.py` بـStreamlit أو Gradio: upload صورة اختياري، textarea اختياري، زر Analyze، وتحذير إذا غاب الاثنان. لا تعرض embedding أو key. اعرض: المدخلات، تحليل النص، قناع/overlay الصورة، fusion confidence، الحقول المنظمة، السياسة عند وجودها، والتقرير النهائي.

## حالات E2E الملزمة

| الحالة | النتيجة المتوقعة |
|---|---|
| نص فقط | تحليل نص + تصريح غياب دليل صورة |
| صورة فقط | قناع/ثقة صورة + عدم اختراع طلب المستخدم |
| كلاهما | دمج الأدلة واستدعاء السياسة فقط عند الطلب |
| لا عيب واضح | عدم يقين/نتيجة سليمة بلا ادعاء عيب |

أنشئ `tests/test_e2e.py` مع mocks للـLLM عند CI. شغّل يدوياً بartifacts فعلية وسجل screenshots/traces وإصدارات models. تحقق من الرسائل للملف غير المدعوم والصورة التالفة وفشل LLM.

**بوابة الخروج:** السيناريوهات الأربعة تمر، والـDemo يشغل من تعليمات جديدة بلا إعداد خفي.
